# 费用报销制度

## 总则

本制度规范云雀科技员工的差旅、交通、餐饮、办公用品等费用的申请与报销流程。
所有费用须遵循"真实发生、与业务相关、凭证齐全、事前审批"四项原则。
不符合任一原则的费用，财务有权退回。

## 审批权限

| 单笔金额（元） | 审批人 |
| --- | --- |
| 0 – 2,000 | 直属主管 |
| 2,001 – 10,000 | 部门负责人 |
| 10,001 – 50,000 | 分管副总裁 |
| 50,000 以上 | CFO |

审批通过后的单据须在 **30 个自然日内** 提交财务，逾期视为放弃；跨年度单据一律不予受理。

## 差旅标准

**交通**

- 飞机：总监及以上可乘公务舱；其他员工经济舱。单程飞行时间超过 5 小时且为红眼航班的可申请公务舱，需副总裁审批。
- 高铁：4 小时以内行程原则上乘高铁二等座，总监及以上可乘一等座。
- 市内交通：实报实销，单次超过 200 元需说明事由。

**住宿**（每晚上限，含税）

| 城市级别 | 上限（元/晚） |
| --- | --- |
| 一线城市（北上广深） | 700 |
| 新一线及省会城市 | 500 |
| 其他城市 | 350 |

超标部分由个人承担，但因会展、旺季导致全城涨价的，可凭当日同区域三家酒店报价截图
提前申请特批。

**餐补**

出差期间按 **120 元/天** 计发，无需发票，随报销单一并申领。当日往返不享受餐补。
招待客户的餐费按实际发生报销，需附客户名单与用餐事由，人均超过 300 元的需部门负责人审批。

## 报销流程

1. 事前申请：在费控系统创建"出差申请"或"费用预申请"，获得审批号；
2. 消费与留票：索取合规发票，抬头必须为公司全称与纳税人识别号；
3. 填写报销单：关联审批号，上传发票原件扫描件，填写成本中心；
4. 审批流转：按上表权限自动路由；
5. 财务复核与付款：**每周二、周五** 两次集中付款，付款后 3 个工作日到账。

## 发票要求

- 必须为增值税发票（专票或普票），电子发票需提供 PDF 原件，不接受截图；
- 发票抬头：云雀科技有限公司；纳税人识别号：91310000MA1FLXXX00；
- 发票内容须与实际消费一致，不得开具"办公用品"笼统科目用于餐饮或交通；
- 单张发票金额超过 5,000 元的，需在发票背面注明用途并签字。

**不予报销的项目**：烟酒、娱乐场所消费、个人物品、罚款、因个人原因产生的退改签费用、
未事前审批的支出。

## 特殊情形

**紧急出差来不及事前审批怎么办？**
可先在企业微信向直属主管发起文字确认，回程后 3 个工作日内在费控系统补单，
并附上当时的确认截图，否则按未审批处理。

**发票丢失怎么办？**
可向开票方索取发票记账联复印件并加盖发票专用章，同时提交情况说明，
由财务负责人签批后可报销，同一年度内每人不超过 2 次。

**团建费用怎么走？**
团建属于福利费，不走差旅标准，人均上限 **300 元/次**，每季度一次，
由部门负责人审批后从部门福利预算列支。
